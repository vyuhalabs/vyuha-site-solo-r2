# Changelog

## 0.1.0

First release of the site.

- Home page: what vyuha is and who it is for, the model in seven parts, illustrations of the Inbox, a run with its evidence, the decision matrix and a playbook's stages.
- Getting-started guide, the model in full, and a short FAQ.
- Next step: the guide first, then an access request on GitHub.
- Light and dark themes, self-hosted fonts, no client-side JavaScript, no cookies.
- Per-page titles, descriptions, canonical links, Open Graph and Twitter cards with generated images; `sitemap.xml` and `robots.txt`.
- Workflows: `build`, `quality` and `deploy` to GitHub Pages.
