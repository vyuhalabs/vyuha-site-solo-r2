Access is by request for now. [Open an access request](https://github.com/vyuhalabs/vyuha-site-solo-r2/issues/new?template=access-request.yml) on GitHub. The request is public, so leave out anything private. Read the [getting-started guide](../docs/getting-started/) first so you know what you will set up.
